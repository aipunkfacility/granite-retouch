# Preserve

Render the original clothing matching the source photo exactly — same cut, proportions, and authentic details. The resulting clothing must look crisp with clear tonal definition, clearly defined against the subject's skin and the background.

Render clothing in gray tonal ranges — solid white or solid black areas lose detail on stone. Match each garment's tonal range to the source. Prioritize detail over brightness — when detail and brightness conflict, render darker. Render clothing with clear tonal definition — the fabric structure must read clearly through tonal variation between light and shadow. Render all readable details from the original — the client knows every item by heart and will notice any omission.

Render dark clothing with visible tonal transitions from fold structure throughout — the clothing reads as dimensional fabric, not a flat dark area. Keep dark clothing shadows above 0 except deep seam lines.

Render collar lines and lapel edges razor-sharp with clean 3D definition.
