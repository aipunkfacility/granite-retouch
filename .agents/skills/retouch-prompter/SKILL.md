# Retouch Prompter Skill

Вы — мастер промпт-инжиниринга. Ваша задача — собрать идеальный промпт для нейросети, используя блоки из папки `prompt_blocks`.

## Контекст

Ты собираешь промпт для AI-ретушёра, который генерирует изображение на синем (#0000FF) фоне. Это изображение затем гравируется на камне.

**Принцип генерации:** Ретушь — это полная перегенерация изображения нейросетью, а не коррекция исходного фото. Нейросеть получает исходник как референс для идентичности и генерирует лицо, волосы, одежду, фон — с нуля, с нужными параметрами для технологии гравировки.

**Совместимость с пайплайном:** Пайплайн программно добавляет: (1) контурный свет — outer glow для лазера, inner glow для импакта; (2) арховую виньетку. Промпт не должен инструктировать модель генерировать эффекты, которые пайплайн добавляет автоматически — это создаёт двойной контур или конфликт с виньеткой.

**Хромакей:** Чистый синий (#0000FF) фон критичен для алгоритма хромакея, отделяющего субъект от фона. Генерация градиентов, паттернов или текстур на фоне нарушит разделение.

**Формула сепарации — ключ к пониманию всей сборки:**

- **Лазер** = тёмная обводка субъекта (в промпте) + внешний glow (добавляется пайплайном после генерации). Тёмный контур в лазерных блоках — это техническая «стена», не дающая светлым краям субъекта слиться с внешним glow в одно пятно.
- **Импакт** = только rim light / inner glow внутри силуэта (добавляется пайплайном). Внешнего glow нет — сепарация через контровой свет, обводящий силуэт изнутри.

Анти-кукла (Guideline 4) применяется к чертам лица — плавные тональные переходы, без графических контуров. Это НЕ относится к контуру силуэта — там, наоборот, нужен чёткий тональный разрыв между субъектом и фоном.

## Алгоритм работы

1. **Прочитай** `order.json` (ID заказа, тип станка, данные анализа).
2. **Определи** набор блоков для сборки:
   - **Основа**: `prompt_blocks/base.md` (Role/Context, Guidelines 1, 1.5, 2 Lighting, 3 Background, 4 Anti-Doll).
   - **Композиция**:
     - Если в `analyzer_output` или запросе указан `full_body: true` → `prompt_blocks/composition/full-body.md`.
     - Иначе → `prompt_blocks/composition/portrait.md`.
   - **Одежда**:
     - Если в `analyzer_output` или запросе не указана ЗАМЕНА (military/civilian) → `prompt_blocks/clothing/preserve.md`.
     - Иначе → соответствующий блок `civilian.md` или `military.md`.
   - **Головной убор**:
     - Если нужно оставить как есть → `prompt_blocks/headgear/preserve.md`.
     - Если нужно убрать → `headgear/none.md`.
     - Если нужно добавить кепку → `headgear/cap.md`.
   - **Станок**: прямое сопоставление по `machine_type`:
     - "laser_standard" → `prompt_blocks/laser.md`
     - "laser_80w" → `prompt_blocks/laser-80w.md`
     - "impact" → `prompt_blocks/impact.md`
   - **Ограничения**: `prompt_blocks/constraints.md` (универсальные требования к результату, всегда включается).
3. **Проанализируй** одежду и сформируй тональное описание (для всех clothing-блоков):
   - Прочитай `analyzer_output` или визуально оцени исходник по категориям:
     - Тип одежды (рубашка, пиджак, платье, форма и т.д.)
     - Цвет / тональность → перекодируй по таблице (brightness, шкала 0–255):
       - Белая / очень светлая → light gray (brightness 160–200)
       - Средне-серая → medium gray (brightness 100–160)
       - Тёмная → dark gray (brightness 40–100)
       - Очень тёмная / чёрная → charcoal gray (brightness 20–60)
     - Детали: воротник, лацканы, пуговицы, карманы, швы, складки, вышивка, медали, эполеты и т.д.
   - **Селективная подстановка:** включай в промпт только те тональные диапазоны, которые соответствуют реальной одежде на исходнике. Если светлой одежды нет — не упоминай диапазон light gray. Если есть и светлые, и тёмные элементы — включи оба диапазона. Каждая инструкция в промпте должна относиться к тому, что реально есть на изображении.
   - Сформируй описание одежды для подстановки в clothing-блок. Все значения подставляй на английском:
     «Render the subject's [tone] [garment type] (brightness [range]) with [detail list]. Set the [garment type] in the [range] brightness range.»
   - Если clothing-блок = preserve — опиши оригинальную одежду с перекодировкой тона.
   - Если civilian / military — опиши замещающую одежду с соответствующим диапазоном.
   - **Жёсткое правило:** clothing brightness ≤ face brightness. Лицо — самый яркий элемент портрета.
   - **Интеграция в блок:** вставь сформированное описание одежды отдельным абзацем *перед* пунктом «Clothing Tonal Rule» в clothing-блоке. В самом пункте «Clothing Tonal Rule» вычеркни строки с тональными диапазонами, отсутствующими на исходнике, — оставь только актуальные диапазоны.
4. **Собери** промпт в следующем порядке:
   - Блок `base.md` (Role/Context, Guidelines 1, 1.5, 2 Lighting + Brightness Ceiling).
   - Блок композиции.
   - Блок одежды (адаптированный по результатам шага 3: тональная рекодировка + перечень деталей).
   - Блок головного убора.
   - Блок станка (техническая часть: кожа, волосы, контраст, сепарация краёв).
   - Блок `base.md` (продолжение: Guideline 3 Background, Guideline 4 Anti-Doll).
   - Блок `constraints.md` (универсальные требования к результату).
   - Блок станка (Goal).
5. **Сохрани** финальный результат в `prompt.md` и обнови `order.json`.

## Важно

Используй тексты из файлов блоков как основу. Адаптируй clothing-блоки по результатам анализа исходника (шаг 3): подставляй конкретные тональные диапазоны, перечисляй детали одежды. Блоки, не требующие адаптации (base, composition, headgear, constraints, машинные блоки), используй дословно, без изменений.
