## Оборудование

Программа Engrave (САУНО) — управляющее ПО для гравировальных станков серии «График» (SAUNO).
Сайт: sauno.ru. Текущая версия: 12.2. Работает под Windows XP/Vista/7/8/10 (32/64 bit).

Альтернативное ПО: STONE-ГРАФ. Сообщество: graverstone.ru (форум).

### Модели станков

| Модель | Метод | Рабочее поле | Лазер |
|--------|-------|--------------|-------|
| График-3К | Ударный | 600×760 / 600×1200 / 800×1900 мм | — |
| График-3КП | Ударный (планшетный) | 300×400 / 400×600 / 600×900 / 600×1350 мм | — |
| График-3КЛ | Ударный + лазерный | 550×900 / 650×1100 / 750×1350 / 750×1550 мм | CO2, 40Вт (до 120Вт) |
| График-3КЛД | Ударный + лазерный | те же | Диодный |

### Технические характеристики (ударная гравировка)

- Точность позиционирования: 0.0125 мм
- Число полутонов: до 256
- Глубина изображения: 0.1–0.8 мм (на мраморе до 1.5 мм)
- Производительность: 300×400 мм за 20–90 мин (зависит от режима)
- Срок службы иглы: ≥10 изображений 300×400 мм
- Твёрдость материала: 2–7 по Моосу

### Технические характеристики (лазерная гравировка, CO2)

- Мощность: 40Вт (возможна установка до 120Вт)
- Срок службы излучателя: до 3000 часов
- Скорость гравирования: до 500 мм/с
- Фокусное расстояние: 50.8 мм (2 дюйма)
- Охлаждение: водяное замкнутое, 10–25°C

### Технические характеристики (лазерная гравировка, диодный)

- Срок службы: 20 000 часов (vs 3000–5000 у CO2)
- Мощность: до 80Вт
- Без водяного охлаждения
- Проще замена излучателя (нет системы зеркал, не нужна юстировка)
- Нет параметра E (экспозиция) — только P (мощность)

### Общие характеристики (оба типа лазера)

- Шаг позиционирования: 0.025 мм
- Плотность точек: 10–400 точек/см, макс. 160 000 точек/кв.см (1016 dpi)
- Число полутонов: до 256
- Автоматическое отслеживание уровня поверхности
- 3-координатный привод (ШВП)

## Форматы файлов

Engrave принимает:
- **BMP 8-bit** (256 оттенков серого) — **основной формат** для лазерных и ударных станков
- **BMP 1-bit** (двоичный растр) — для мощных лазеров с Jarvis/Stucki дизерингом
- **PSD** (Photoshop) — с сохранением структуры слоёв и масок
- Векторные: *.GVC (собственный), *.DXF, *.TAP (G-код)

**⚠️ Engrave НЕ учитывает корректирующие слои Photoshop** (Яркость/Контраст, Уровни и т.д.) — только растровые слои.

Размеры: типично 30×40 см или 40×40 см. Шаг по умолчанию: 0.300 мм (84.6 dpi).

### ⚠️ DPI в BMP и шаг Engrave — КЛЮЧЕВОЙ МОМЕНТ

**Engrave НЕ использует DPI из заголовка BMP.** Шаг гравирования задаётся оператором в панели «Материал» (поле «Шаг»). DPI вычисляется из шага:

```
Разрешение [dpi] = 25.4 / шаг [мм]
```

Если разрешение BMP не соответствует шагу в Engrave, программа выводит **предупреждение о несоответствии разрешений**, но не использует DPI из BMP для управления станком.

**Рекомендация для пайплайна:** при создании BMP записывать в заголовок DPI, соответствующий шагу станка (чтобы Engrave не ругался), но не считать это критичным для результата гравировки.

### ⚠️ 8-bit vs 1-bit — КРИТИЧЕСКИЙ ВЫБОР ДЛЯ ПАЙПЛАЙНА

**Engrave выполняет собственное растрирование из 8-bit grayscale!** Это основа всей технологии САУНО:

1. Оператор открывает **8-bit grayscale** BMP в Engrave
2. Engrave читает яркость каждого пикселя (0–255)
3. Engrave преобразует полутона в растр **своими алгоритмами** (Р1–Р5)
4. Для лазера: мощность импульса **пропорциональна яркости пикселя** (график P от яркости)
5. Для ударного: сила удара **пропорциональна яркости** (график A от яркости)

**При подаче 1-bit BMP (с нашим Jarvis-дизерингом):**
- Engrave теряет возможность модулировать мощность/силу по яркости — все точки «одинаковы»
- Engrave не может применять свои алгоритмы Р1–Р5 — нет полутонов для растрирования
- Результат: гравировка «плоская», нет градаций яркости точек
- Это эквивалент работы традиционного лазерного гравера (у которого диаметр и глубина точек одинаковы)

**Вывод: `export_mode: "8bit"` должен быть режимом ПО УМОЛЧАНИЮ для станков САУНО.**

## Алгоритмы растрирования Engrave (Р1–Р5)

> Доступны **только в точечном режиме**. В амплитудном режиме — только квадрат/диагональ расположение точек.

Engrave имеет 5 **собственных** алгоритмов растрирования, разработанных специально для гравировки камня. Это **не** стандартные алгоритмы типа Floyd-Steinberg или Jarvis — это проприетарные методы САУНО.

| Метод | Название | Описание |
|-------|----------|----------|
| **Р1** | Стандартный растр | Базовый метод плотностного растрирования |
| **Р2** | Модифицированный растр | **По умолчанию.** Улучшенное распределение точек, оптимизировано для камня |
| **Р3** | Диагональный растр | Точки расположены по диагонали (в шахматном порядке) |
| **Р4** | Растр-шаблон | С настраиваемым размером элемента (М170, М190, М210) |
| **Р5** | Растр-шаблон модифицированный | Улучшенный шаблон с настраиваемым размером элемента (М140, М170, М200) |

**Ключевое отличие от стандартного дизеринга:** Алгоритмы САУНО одновременно управляют:
1. **Плотностью точек** — чем ярче пиксель, тем больше точек в этой области
2. **Мощностью/силой каждой точки** — чем ярче пиксель, тем сильнее удар или больше мощность лазера

Стандартный дизеринг (Jarvis, Floyd-Steinberg) управляет только плотностью, а мощность/сила одинакова для всех точек.

## Режимы гравирования

### Точечный режим (по умолчанию, единственный для лазера)
Чем ярче (белее) участок, тем плотнее точки и сильнее удар/мощность. Плотность — автоматически (алгоритмы Р1–Р5), мощность/сила — через графики в панели «Материал».

### Амплитудный режим
Точки на одинаковом расстоянии (квадратная сетка). Яркость — только за счёт изменения силы удара. **Недоступен при лазерном гравировании.**

### Комбинированный режим
Структура точек напоминает ручную гравировку. Нет сетки и артефактов точечного режима. Изображение ярче, чем в других режимах. Подрежимы A/B/C: от минимальной плотности (A, быстро) до максимальной (C, медленно). **Недоступен при лазерном гравировании и многослойных макетах.**

## Шаг гравирования

Шаг = расстояние между точками в мм. Обратная зависимость от разрешения:

```
Разрешение [точек/см] = 10 / шаг [мм]
Разрешение [dpi] = 25.4 / шаг [мм]
```

| Шаг | Разрешение (пикс/см) | Разрешение (dpi) |
|------|---------------------|-----------------|
| 0.10 мм | 100 | 254 |
| 0.15 мм | 66.67 | 169.3 |
| 0.20 мм | 50 | 127 |
| 0.25 мм | 40 | 101.6 |
| 0.30 мм | 33.33 | 84.6 (по умолчанию) |
| 0.35 мм | 28.57 | 72.6 |
| 0.40 мм | 25 | 63.5 |
| 0.45 мм | 22.22 | 56.4 |
| 0.50 мм | 20 | 50.8 |

**Практические советы из мануала:**
- Маленькие картинки / много деталей → уменьшить шаг (0.200–0.250)
- Мягкий камень (мрамор) → увеличить шаг (0.350–0.400), иначе точки сольются
- При уменьшении шага обычно уменьшают и амплитуду (силу удара), чтобы не «перебить»
- Диапазон для камня: **0.200–0.400 мм**
- Для лазера: **0.125–0.250 мм** (шаг меньше, чем для ударного)
- Рекомендация для обучения: шаг 0.225 для базальта, 0.275 для габбро

## Настройка силы удара (ударный)

Параметры A2 (сила на сером) и Amax (сила на белом) — регулируются в полноэкранном режиме (F5) или через панель «Материал».

**Нелинейная регулировка графика амплитуды:**
- До 10 узловых точек на графике «яркость → сила удара»
- Дополнительные точки изгиба для каждого узла
- Позволяет точно настроить передачу конкретных полутонов
- Можно редактировать прямо в процессе гравировки

## Настройка лазера

Параметры:
- **P** (мощность, %): сила лазерного импульса (0–100%)
- **E** (экспозиция, %): длительность импульса (только CO2, нет у диодного)
- **V** (скорость подачи, мм/мин): при увеличении — быстрее, но слабее и мельче

На практике обычно достаточно регулировать только мощность P.

## Предварительный просмотр на камне (F11)

Engrave моделирует структуру камня, показывая, как будет выглядеть результат гравировки.

**⚠️ Критическое ограничение:** режим предпросмотра работает **только если компьютер подключён к станку кабелем связи и станок включён**. Без станка — окно с предупреждением.

**Как включить:** Вид → Предварительный просмотр на камне, кнопка с «чёрными очками», или F11.

**Как задать качество камня:** Вид → Настройки просмотра (Ctrl+F11). Параметр «Степень неоднородности» — чем больше число, тем более неоднородна структура.

**Что показывает:**
- Уменьшение контраста изображения
- Потерю деталей в полутонах (причёска, морщины)
- Влияние неоднородности камня на результат
- Области, которые будут выглядеть «плоско»

**Время подготовки:** зависит от размеров изображения, вычисления в фоне (индикатор «S» с процентом).

## Слои и маски

### Слои (до 31)
- Каждый слой — отдельное растровое или векторное изображение
- Можно задать индивидуальные параметры материала (шаг, сила удара, частота)
- Слои повторного прохода: то же изображение, другие параметры
- Порядок гравировки: снизу вверх
- Макет сохраняется в файле *.grl

### Маски
- Маска создаётся в Photoshop (Слои → Слой-маска → Показать всё)
- Чёрная кисть — скрыть область, белая — показать
- Перенос из Photoshop: копирование-вставка (Ctrl+Shift+C → Ctrl+Alt+V) или через PSD
- В Engrave: инверсия маски (Ctrl+Shift+I) — гравировать всё кроме выделенного

**Типичный workflow с масками:**
1. Маской выделить лицо → гравировать новой иглой, медленнее, выше качество
2. Инверсия маски → гравировать фон изношенной иглой, быстрее

### PSD-импорт
Engrave открывает *.psd с сохранением слоёв и масок. Слой с именем «контур» или «contour» автоматически становится контуром заготовки.

## Выделение полутонов

Engrave может выделять цветом отдельные полутона на картинке:
- Shift + клик на графике амплитуд → выделить полутона
- Красным отмечаются области изображения с выбранным диапазоном оттенков
- Можно гравировать только выделенные полутона (Режимы → Гравирование полутонов)

**Полезно для:** анализа качества ретуши — видеть, какие полутона присутствуют или отсутствуют.

## Режим «Контраст»

Режим «Контраст» позволяет получить при повторном проходе более яркую картинку.
- Устанавливается только для слоёв повторных проходов
- Действует только при включённом «Повторном проходе»
- Включение: Работа → Контраст

## Режим ячеек

Автоматическое разделение изображения на фрагменты для пропуска чёрных областей. Значительно сокращает время гравировки (для изображений в рамке, надписей, нескольких фрагментов).

## Неоднородность камня

Гранит и габбро — неоднородные материалы. Камень содержит вкрапления минералов разного цвета и твёрдости. При гравировке эта неоднородность «съедает» контраст:

- На мониторе ретушь выглядит контрастной и детализированной
- На камне полутона сливаются, детали теряются
- Чем выше неоднородность камня, тем сильнее потери

**Параметр «Неоднородность»** в Engrave (Ctrl+F11):
- Диапазон: 0–5
- По умолчанию: 2 (типичный гранит)
- 0 = идеальный однородный камень (не существует в природе)
- 5 = очень пятнистый камень

## Компенсация потерь на камне

Ретушёры работают циклом: обработал → проверил в Engrave → вернулся → усилил → снова проверил.

**Методы компенсации (из видео Engrave):**

1. **Яркость/Контрастность:** уменьшить яркость, увеличить контраст
2. **Levels:** уменьшить гамму (усиливает средние тона)
3. **Smart Sharpen / Unsharp Mask:** усилить резкость
4. **Dodge/Burn:** выправить пересветы и провалы после усиления контраста

**Принцип:** на мониторе ретушь должна выглядеть **переконтрастированной** — на камне контраст всё равно упадёт. Чем хуже камень (выше неоднородность), тем агрессивнее компенсация.
