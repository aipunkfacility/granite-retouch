## 2. Управляющее ПО — критичные различия для пайплайна

Формат BMP и способ его обработки — главный фактор для выбора `export_mode`. Разные ПО по-разному работают с 8-bit и 1-bit файлами.

### 2.1. САУНО Engrave

См. подробнее: [engrave.md](engrave.md)

| Параметр | Поведение |
|----------|-----------|
| **DPI из заголовка BMP** | НЕ использует для управления станком. Предупреждает при несоответствии шагу в Engrave. Рекомендация: записывать `dpi = 25.4 / step_mm` |
| **8-bit BMP** | Основной формат. Engrave читает яркость каждого пикселя (0–255), применяет свои алгоритмы растрирования Р1–Р5. Для лазера: мощность импульса пропорциональна яркости. Для ударного: сила удара пропорциональна яркости |
| **1-bit BMP** | Теряет возможность модулировать мощность/силу — все точки одинаковы. Алгоритмы Р1–Р5 не работают (нет полутонов для растрирования). Результат: «плоская» гравировка |
| **Нелинейные графики** | Есть: до 10 узловых точек на графике «яркость → мощность/сила». Можно редактировать в реальном времени (F5) |
| **Алгоритмы растрирования** | 5 проприетарных методов Р1–Р5. Одновременно управляют плотностью И мощностью точек — ключевое отличие от стандартного дизеринга |
| **Версия** | Текущая: 12.2. Работает под Windows XP/Vista/7/8/10 (32/64 bit) |

**Вывод для пайплайна:** `export_mode: "8bit"` — безальтернативный выбор для САУНО. 1-bit лишает станок главного преимущества (модуляция мощности по яркости).

### 2.2. Mirtels MTGCAM / SIACAM

| Параметр | Поведение |
|----------|-----------|
| **DPI из заголовка BMP** | Используется для определения разрешения. Станок читает BMP с USB-Flash. Рекомендация: корректный DPI в заголовке |
| **8-bit BMP** | Основной формат. «Рабочая картинка открывается в формате BMP, 256 оттенков серого». Точечный/амплитудный/комбинированный режимы — сила удара или мощность лазера варьируется по яркости пикселя |
| **1-bit BMP** | Поддерживается, но теряется модуляция силы/мощности |
| **Нелинейные графики** | Есть в MTGCAM. Для лазера: «в программе станка устанавливаются только три параметра: скорость, мощность и шаг» |
| **Функция «растеризация»** | В MTGCAM — управление плотностью точек (аналог алгоритмов Р1–Р5 в САУНО) |

## 3. Физика гравировки — связь с параметрами конфига

### 3.1. Лазер 20–40W (CO2)

**Физика:** Лазер выжигает (плавит) камень. При 20–40W неглубокое выжигание — нужен high-key (много светлых пикселей → плотные точки сливаются в изображение).

| Параметр конфига | Значение | Обоснование |
|------------------|----------|-------------|
| `machine_type` | `laser_standard` | Стандартный лазер |
| `face_brightness_target` | 230–245 | Много светлых точек → изображение читается на камне |
| `white_ceiling` | 250 | Запас до 255 предотвращает «прожог» |
| `stone_gamma` | 0.88 | Осветление теней — лазер не прорабатывает глубокие тени |
| `step_mm` | 0.300 | Стандартный шаг для лазера 20–40W |
| `export_mode` | `"8bit"` | Модуляция мощности по яркости |
| `glow_size` | 40–80 px | Широкий мягкий контур — голова не сливается с фоном |

### 3.2. Лазер 60–80W+ (CO2 / диодный)

**Физика:** Глубокое выжигание. Яркие участки пережигаются в белое пятно. Нужен medium-key — меньше яркость, Engrave/ПО модулирует мощность через Р-графики.

| Параметр конфига | Значение | Обоснование |
|------------------|----------|-------------|
| `machine_type` | `laser_80w` | Мощный лазер |
| `face_brightness_target` | 160–180 | Medium-key — Engrave сам усиливает через Р-графики |
| `white_ceiling` | 235 | Строже: при 60–80W значения > 235 пережигаются |
| `stone_gamma` | 1.0 | При 8-bit Engrave сам управляет яркостью, гамма не нужна |
| `step_mm` | 0.250 | Меньше шаг → выше детализация (по мануалу САУНО: 0.125–0.250) |
| `export_mode` | `"8bit"` | Модуляция мощности по яркости |
| `glow_size` | 15–25 px | Минимальный — мощный лазер сам создаёт контраст |

**Исключение — Stanzone лазерный модуль:** Работает только в 1-bit. Требует `export_mode: "1bit"` + `dither_method_1bit: "jarvis"`. Все точки одинакового размера, яркость — только плотностью.

### 3.3. Ударный

**Физика:** Алмазная игла бьёт по камню с разной силой (256 уровней). Чем сильнее удар → больше белая точка (микроскол). В полностью чёрных областях игла не бьёт — застой.

| Параметр конфига | Значение | Обоснование |
|------------------|----------|-------------|
| `machine_type` | `impact` | Ударный станок |
| `face_brightness_target` | 200–225 | Умеренная яркость — игле нужен материал для полутонов |
| `white_ceiling` | 240 | Игла может сломаться/выкрошить камень при 255 |
| `stone_gamma` | 0.90 | Лёгкое осветление теней |
| `step_mm` | 0.300 | Стандартный шаг для ударного |
| `export_mode` | `"8bit"` | 256 уровней силы удара |
| `shadow_floor` | 8 | Предотвращает застой иглы на чёрном |
| `shadow_noise` | 5–15 | Даёт игле «зацепку» в глубоких тенях |
| `glow_size` | 10–25 px | Узкий яркий контур — игла хорошо считывает границу |

### 3.4. Шаг гравировки (step_mm)

Шаг = расстояние между точками в мм. Обратная зависимость от разрешения: `dpi = 25.4 / step_mm`.

| Шаг (мм) | DPI | Применение |
|-----------|-----|------------|
| 0.100 | 254 | Максимальная детализация, мелкие изображения |
| 0.125 | 203 | Лазер: минимальный рекомендуемый (САУНО) |
| 0.150 | 169 | Высокая детализация, мелкие портреты |
| 0.200 | 127 | Детальные портреты, твёрдый камень |
| 0.225 | 113 | Рекомендация для базальта |
| 0.250 | 102 | Лазер: стандартный; Ударный: детальный |
| 0.275 | 92 | Рекомендация для габбро |
| 0.300 | 85 | Ударный: стандартный (по умолчанию) |
| 0.350 | 73 | Мягкий камень (мрамор) |
| 0.400 | 64 | Мрамор, крупный шаг (точки сливаются на мягком камне) |

**Практические правила из мануалов и форумов:**
- Маленькие картинки / много деталей → уменьшить шаг (0.200–0.250)
- Мягкий камень (мрамор) → увеличить шаг (0.350–0.400), иначе точки сольются
- Лазер: шаг меньше, чем ударный (0.125–0.250 мм), т.к. луч тоньше иглы
- При уменьшении шага обычно уменьшают и амплитуду (силу удара), чтобы не «перебить»
- Не рекомендуется 300 dpi на ударных станках — дробное количество микрошагов, лучше 212 dpi (шаг ~0.120)

## 4. Материалы и их влияние на параметры

### 4.1. Гранит

- **Твёрдость:** 6–7 по Моосу
- **Неоднородность:** Средняя–высокая (крупнозернистый). «Съедает» контраст
- **Шаг:** 0.250–0.300 мм
- **`stone_gamma`:** 0.85–0.90 (осветление теней для компенсации потери контраста)
- **Рекомендации:** Переконтрастированная ретушь — на камне контраст упадёт. Предпросмотр в Engrave (F11) с неоднородностью 2–3

### 4.2. Габбро / Габбро-диабаз

- **Твёрдость:** 5–6 по Моос
- **Неоднородность:** Низкая–средняя (мелкозернистый, тёмный). Лучше для гравировки
- **Шаг:** 0.275–0.350 мм
- **`stone_gamma`:** 0.88–0.92
- **Рекомендации:** Оптимальный камень для портретной гравировки. Тёмный фон → хороший контраст. Рекомендация САУНО: шаг 0.275

### 4.3. Мрамор

- **Твёрдость:** 3–4 по Моос (мягкий)
- **Неоднородность:** Низкая (однородный), но пористый
- **Шаг:** 0.350–0.400 мм (увеличенный — иначе точки сливаются)
- **`stone_gamma`:** 0.92–1.0 (меньше коррекции — камень мягкий, хорошо передаёт полутона)
- **Рекомендации:** Лазер предпочтительнее ударного (мрамор хрупкий, игла может сколоть). Мягкий камень — точки сливаются при мелком шаге. Глубина гравировки до 1.5 мм

### 4.4. Базальт

- **Твёрдость:** 5–6 по Моос
- **Неоднородность:** Низкая (мелкозернистый)
- **Шаг:** 0.225–0.275 мм
- **`stone_gamma`:** 0.88–0.90
- **Рекомендации:** Рекомендация САУНО: шаг 0.225. Мелкозернистый — хорошо для детальных портретов

### 4.5. Стекло

- **Твёрдость:** 5.5–6.5 по Моос
- **Шаг:** 0.100–0.200 мм (очень мелкий)
- **Метод:** Только лазерный (CO2). Ударный расколет стекло
- **`export_mode`:** Зависит от ПО станка

## 6. Типичные проблемы и их причины

| Проблема на камне | Причина | Параметр конфига | Решение |
|-------------------|---------|-------------------|---------|
| «Плоское лицо» без полутонов | `export_mode: "1bit"` для станка, поддерживающего 8-bit | `export_mode` | Переключить на `"8bit"` — станок сам растрирует полутона |
| Пережжённые блики на лице | `white_ceiling` слишком высокий для мощности лазера | `white_ceiling` | Снизить: 250→235 для 60–80W, 235→225 для Stanzone лазер |
| Игла застревает на чёрном (impact) | Нет минимальной яркости в тенях | `shadow_floor`, `shadow_noise` | Добавить `shadow_floor: 8`, `shadow_noise_min: 5` |
| Серая дымка на фоне | Коррекция яркости без маски субъекта | `subject_mask` | Убедиться, что маска передаётся в apply_levels / apply_unsharp |
| Голова обрезана виньеткой | `headroom` слишком маленький | `vignette.headroom` | Увеличить headroom (0.6→0.8) |
| Лесенка на контуре | Бинарная маска хромакея | `mask_soft_sigma` | Использовать градиентную маску (sigma=1.5) |
| Пиксельная сетка на гравировке | DPI не соответствует шагу станка | `step_mm` → DPI | Записывать `dpi = 25.4 / step_mm` в заголовок BMP |
| Панно-Граф не видит BMP | Некорректный DPI из Photoshop | DPI в BMP | Явно указывать DPI при сохранении из Photoshop |
| Разный результат preview и export | Glow рандомизировался | `glow_style` | Glow детерминирован (D.1) — midpoint вместо random |
| Медленная гравировка | Шаг слишком мелкий для данного камня | `step_mm` | Увеличить шаг: 0.250→0.300 для гранита, 0.300→0.350 для мрамора |
| Точки сливаются на мраморе | Шаг слишком мелкий для мягкого камня | `step_mm` | Увеличить до 0.350–0.400 мм |
