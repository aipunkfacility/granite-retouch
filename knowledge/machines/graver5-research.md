## 2. Управляющая программа «Гравёр 5.2x»

### Версии прошивки
- **5.20.11** — базовая, есть обучающее видео на YouTube
- **5.20.15** — более новая, упоминается на форуме
- **5.22** — версия, на которой работают опытные операторы

### Цепочка подготовки файла

```
Photoshop CS6 (ретушь, слои, .PSD)
        ↓
Программа «Гравёр 5» (на ПК) — открывает PSD/BMP/GIF/JPG
        ↓                         ↳ интерпретирует слои из PSD
        ↓                         ↳ каждый слой = отдельный проход с настройками
        ↓
Экспорт → .GRV (собственный формат станка)
        ↓
SD-карта → Станок читает только .GRV
```

### Поддерживаемые форматы

| Формат | Чтение | Запись | Примечание |
|--------|--------|--------|------------|
| **PSD** | ✅ | — | Со слоями! Каждый слой — отдельный проход гравировки |
| **BMP** | ✅ | — | 8-bit Grayscale, растровый без слоёв |
| **JPG** | ✅ | — | Без слоёв |
| **GIF** | ✅ | — | Без слоёв |
| **GRV** | — | ✅ | Собственный формат для станка, записывается на SD-карту |

**Важно**: сам станок «Гравёр 5» с SD-карты читает **только .GRV**. Все остальные форматы обрабатываются программой «Гравёр 5» на ПК, которая затем экспортирует .GRV.

### PSD-слои — ключевая функция

Программа «Гравёр 5» **интерпретирует слои из PSD-файла**, и каждый слой можно гравировать с разными настройками. Типовой пример:
- **Слой 1 (портрет)** — одни параметры силы удара и разрешения
- **Слой 2 (текст / ФИО / даты)** — другие параметры, обычно сильнее, крупнее точки

Это критически важно для ретуши: ретушёр работает в PSD со слоями, а программа «Гравёр 5» обрабатывает каждый слой отдельно при создании .GRV.

### Ключевые настройки программы (из форумов)

| Параметр | Описание |
|----------|----------|
| **Каналы 14, 15, 16** | Управление мощностью по оттенкам. 14 — тёмные участки, 16 — самые светлые, 15 — промежуточный тон. Можно убрать 15 и оставить прямую 14→16 |
| **Импульс** | Связан с силой удара. Заводской ~1.200–1.300. Увеличиваешь импульс — белый бьёт сильнее, уменьшаешь — слабее |
| **Период** | Время между ударами, ~2.100 мс |
| **Частота** | 0 Гц (для ударного режима) |
| **Стабилизатор №1** | ~45% (основной) |
| **Стабилизатор №2** | 0% |
| **Фокус** | 1 |
| **Электрозазор** | +12.5% (можно менять в процессе гравировки) |
| **Режимы** | Матричный / Матрично-амплитудный. Твёрдые камни (Индия, Балтика) — матричный |

### Возможности программы «Гравёр 5» (на ПК)

| Функция | Описание |
|---------|----------|
| **Открытие и импорт изображений** | PSD, BMP, JPG, GIF |
| **Настройки гравировки** | Исходное и физическое разрешение, направление, количество проходов, сила удара по оттенкам (через каналы и точки излома на графике) |
| **Конфигурации** | Создание и сохранение наборов настроек для разных материалов и типов работ |
| **Многослойность (PSD)** | Интерпретация слоев из PSD — портрет и текст с разными настройками гравировки |
| **Имитация гравировки** | Предпросмотр траектории работы станка |
| **Обрезка изображения** | Быстрая обрезка чёрных полей |
| **Экспорт .GRV** | Подготовка файла для записи на SD-карту |

### Уникальные возможности станка (по сравнению с САУНО)
- **Изменение настроек в процессе гравировки**: общая яркость, средний тон, сила удара по каналам
- **Встроенные пресеты** для разных камней (для «пристрела»)
- **Работа с SD-карты** — не нужен ПК у станка, станок автономен после загрузки задания
- **Битовая карта** — опциональная покупка, улучшает качество
- **Обход по периметру (F1) и контуру (F2)** — проверка позиционирования на заготовке
- **Продолжение после сбоя питания** — станок запоминает позицию
- **Стартовая точка произвольна** — не только левый верхний угол, можно с центра
- **Адаптивная головка** — для различной толщины материала (плитка или стела)
- **Подстройка силы удара во время гравировки** — для разных оттенков

### Ограничения (по сравнению с САУНО)
- Нет автоподъёма Z-оси при переезде
- Нет возможности запустить отдельный слой для повторного пробития — нужно делать «тысячу манипуляций»
- Нет выхода в ноль станка/заготовки
- Менее интуитивный интерфейс настроек белого/серого

## 3. Ретушь под Гравёр 5 — послойная подготовка в Photoshop

### Общий принцип (из YouTube-уроков и форумов)

Ретушь для ударного станка — **послойная в Photoshop**. Файл подготавливается как **8-битный Grayscale BMP**, который станок читает с SD-карты. Каждый пиксель BMP = сила удара иглы (0 = не бить, 255 = максимальный удар).

### Типовая структура слоёв в Photoshop

По данным YouTube-каналов (видео «Слои для ретуши под гравировальный станок», «Подготовка файла к ретуши», «Обработка фото в фотошопе для гравировки») и форумов:

```
Слой 7: Ореол (белый контур по краю силуэта)
         ↳ Gaussian Blur 10-25px, opacity 60-80%
         ↳ Назначение: камень «съедает» границы — ореол делает силуэт читаемым

Слой 6: Обрезка одежды / доработка фона
         ↳ Чистка краёв одежды, удаление мусора
         ↳ Назначение: чёткий край одежды для станка

Слой 5: Волосы (отдельный слой)
         ↳ Прорисовка прядей, белые хайлайты
         ↳ Назначение: без отдельного слоя волосы сливаются с фоном

Слой 4: Одежда (отдельный слой)
         ↳ Усиление текстуры, складок, пуговиц
         ↳ Levels: затемнить, чтобы не было белого пятна
         ↳ Назначение: станок должен «видеть» текстуру ткани

Слой 3: Лицо (основная ретушь)
         ↳ Гладкая кожа, фарфоровая текстура
         ↳ Устранение пор, шумов, дефектов
         ↳Levels: белый ползунок ~235-245, чёрный ~10-15
         ↳ Назначение: основа портрета, самый важный слой

Слой 2: Чёрно-белая конвертация (Black & White)
         ↳ Blues/Cyans → -100 (убивает синий хромакей)
         ↳ Назначение: перевод в Grayscale с контролем каналов

Слой 1: Исходное фото (фон, не трогаем)
```

### Ключевые этапы обработки

**1. Подготовка файла:**
- Удаление мусора, чистка фона
- Разделение на слои: лицо, волосы, одежда — каждый обрабатывается отдельно
- Замена фона на чёрный (для станка = «не бить»)

**2. Конвертация в Ч/Б:**
- Black & White adjustment layer
- Синий канал в -100 (если хромакей)
- Удаление фона через Color Range → заливка чёрным

**3. Ретушь лица:**
- Гладкая кожа без пор (станок «разносит» каждый пиксель шума)
- Мягкие тональные переходы — никаких резких линий
- Губы — без тёмного контура (на камне = «помада»)
- Нос — без двух тёмных полос (на камне = «чужой нос»)

**4. Волосы:**
- Отдельный слой — без него сливаются с фоном
- Белые хайлайт-полосы — на станке white = гравируется, gray = уже «тёмный»
- Скульптурный объём, не плоские

**5. Одежда:**
- Отдельный слой — нужна текстура!
- Levels затемнить, чтобы не было «белого пятна» (перебел)
- Складки, пуговицы, воротник — всё резкое и контрастное

**6. Ореол:**
- Белый контур по краю силуэта
- Gaussian Blur 10-25px (impact), 40-80px (laser)
- Камень «съедает» границы — без ореола силуэт сливается с фоном
- **Критично для Гравёр 5**: на форуме жалуются на «белый снег» — ореол должен быть тонким, не агрессивным

**7. Финальная обработка:**
- Уровни (Levels): белый ~235-245, чёрный ~10-15
- Unsharp Mask: Amount 80-120%, Radius 1.5-2.0px
- Экспорт: BMP 8-bit Grayscale

## 4. Особенности Гравёр 5 vs другие станки (для проекта)

### Что отличает Гравёр 5 от САУНО/Robotics

| Аспект | САУНО | Гравёр 5 |
|--------|-------|----------|
| **Яркость** | Простые ползунки «белое/серое» | Каналы 14/15/16 + импульс + электрозазор |
| **Слои гравировки** | Можно повторно пробить отдельный слой | Нельзя запустить отдельный слой |
| **Z-ось** | Автоподъём при переезде | Нет автоподъёма |
| **Настройка в процессе** | Ограниченная | Можно менять яркость и средний тон |
| **Прошивка** | Engrave (собственная) | «Гравёр 5.2x» (собственная) |
| **Формат файла для станка** | BMP 8-bit Grayscale | .GRV (собственный) |
| **Формат исходника** | BMP | PSD (со слоями!), BMP, JPG, GIF |
| **Разрешение гравировки** | — | 83.3, 125, 250 DPI |
| **Рекомендуемое разрешение** | — | 125 пикс/дюйм при подготовке в Photoshop |
| **Цена** | ×2 | ×1 |

### Для проекта granite-retouch — что учесть

1. **PSD как исходный формат** — программа «Гравёр 5» читает PSD со слоями, каждый слой — отдельный проход. Наш пайплайн должен учитывать, что результат может быть как BMP (без слоёв), так и PSD (со слоями — портрет отдельно, текст отдельно)
2. **Экспорт .GRV** — финальный формат для станка. Наш пайплайн не создаёт .GRV (это делает программа «Гравёр 5»), но должен отдавать PSD/BMP, готовый к загрузке в программу
3. **Шаг гравировки** — у Гравёр 5 шаг 0.3 мм (по умолчанию), совпадает с impact-пресетом
4. **Перебел** — главная проблема Гравёр 5. На форуме постоянно жалуются. Наш пайплайн уже решает это через `white_ceiling: 240` и `face_brightness_target`
5. **Ореол** — нужен, но тонкий (10-25px), не агрессивный. Наш пайплайн делает это через Inner/Outer Glow
6. **Повторное пробитие** — Гравёр 5 не поддерживает послойную повторную гравировку. Значит, файл должен быть идеальным с первого раза. Наш пайплайн на это и рассчитан
7. **Камень** — карелия (габбро) — основной камень, сильно варьируется по твёрдости. Нужна адаптация gamma/brightness под конкретный камень
8. **Разрешение 125 DPI** — стандартное для Гравёр 5, указано в руководстве.

## 5. Интеграция в granite-retouch

Гравёр 5 **интегрирован** в проект как пресет `graver5-impact` (не как отдельный `machine_type`).

**Причина**: все параметры обработки Гравёр 5 совпадают с типом `impact`.

### Использование

```bash
# Через пресет (рекомендуется)
uv run python -m retouch process -i ai.png -o final.bmp --preset graver5-impact

# Или через impact с ручным указанием камня
uv run python -m retouch process -i ai.png -o final.bmp -m impact --material gabbro
```

### Что было сделано

1. **`presets/graver5-impact.yaml`** — новый пресет с `stone.material: gabbro`
2. **`retouch/presets_catalog.py`** — добавлена запись с brand: graver5
3. **Данная документация** — раздел 5 переписан под статус «интегрировано»

### Что НЕ нужно

| Пункт | Статус |
|-------|--------|
| Новый `machine_type` в `MACHINE_TYPES` | Не требуется — параметры = impact |
| Новый тип в `orders/schema.json` | Не требуется — machine_type = impact |
| Новый тип в CLI choices | Не требуется — используется `--preset` или `-m impact` |
| Новый тип в frontend types | Не требуется — пресет подхватывается API |
| PSD-экспорт со слоями | Пайплайн не поддерживает — оператор открывает BMP/PNG в «Гравёр 5» |
| Генерация .GRV | Не требуется — делает программа «Гравёр 5» на ПК |

### Ограничения

- **Повторное пробитие** — Гравёр 5 не поддерживает послойную повторную гравировку. Файл должен быть идеальным с первого раза. Пайплайн на это и рассчитан
- **125 DPI** — стандартное разрешение подготовки в Photoshop для Гравёр 5 (не путать с `step_mm: 0.300` = ~84.7 DPI машинного шага)
- **Stone** — карелия (габбро), значительно варьируется по твёрдости. При необходимости — ручная подстройка gamma
