# Лазерная гравировка (Diode / CO2)

## Оборудование

Mirtels, Stanzone (Graver PRO) и аналоги.

**Разделение по мощности:**
- **Стандартные 20–40W** — базовые модели для памятников. Целевой стиль: Granite High-End Airbrush (230–245)
- **Мощные 60–80W+** — профессиональные модели с глубоким выжиганием. Целевой стиль: Restored Photograph, Natural Dignified Warm (160–180)

## Специфика технологии

Лазер выжигает (плавит) камень. Он способен передавать очень мягкие полутона (градиенты) и обладает микро-детализацией (толщина луча). При увеличении мощности (60–80W+) выжигание глубже — яркие участки пережигаются, нужен medium-key вместо high-key.

## Требования к файлу

### Стандартные лазеры 20–40W

- **Кожа:** Гладкая, без лишнего «зерна» и резких пор.
- **Одежда:** Максимально резкие текстуры для компенсации плавления краев.
- **Контур:** Мягкий Inner Glow (40-80px), чтобы голова не «сливалась» с чёрным фоном.

### Мощные лазеры 60–80W+

- **Кожа:** Сохранённые морщины, убранные поры/шум — «clean but not sterile».
- **Волосы:** Тёмная масса с мягкими бликами — яркие блики при 60–80W пережигаются.
- **Контур:** Минимальный Inner Glow (15–25px) — мощный лазер сам создаёт контраст.

См. [style-guide-laser-80w.md](../docs/guides/style-guide-laser-80w.md) для деталей.

## Физика

При работе лазера происходит температурное воздействие. Если пересветить лицо в файле, лазер выжжет слишком глубоко и потеряет объем. Если недосветить — портрет будет тусклым.

**Стандартные 20–40W:** Оптимальный диапазон яркости лица: 230–245. Лазер «выжигает» светлые участки, тёмные остаются камнем.

**Мощные 60–80W+:** Оптимальный диапазон яркости лица: 160–180 (медиана). Потолок яркости: 235 — при 60–80W значения выше 235 пережигаются. При 8-bit BMP и gamma=1.0 Engrave сам управляет мощностью через Р-графики. Выжигание глубже, поэтому medium-key вместо high-key.
