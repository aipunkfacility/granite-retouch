# Руководство по пресетам

Пресеты — это предустановленные конфигурации параметров обработки изображения, которые позволяют быстро адаптировать пайплайн ретуши под конкретный станок и материал. Каждый пресет содержит набор ключей: `machine_type`, `step_mm`, `stone_gamma`, `white_ceiling`, `shadow_floor`, `export_mode` и других. Использование пресета гарантирует, что все критичные параметры согласованы между собой, а оператору не нужно вручную подбирать значения для каждого заказа. Пресеты устраняют типичные ошибки: неверный шаг ЧПУ, неподходящий метод дизеринга или завышенный `white_ceiling`, ведущий к пережогу камня. Если вы только начинаете работать с granite-retouch, всегда выбирайте готовый пресет, прежде чем менять отдельные параметры вручную.

## Как выбрать пресет для своего станка

Выбор пресета определяется моделью станка и типом его рабочей головки (лазерная или ударная). В таблице ниже перечислены все поддерживаемые станки, соответствующие им пресеты и ключевые особенности, которые нужно учитывать при запуске обработки. Обратите внимание: указание неверного пресета для станка может привести к браку на изделии, поэтому всегда сверяйтесь с этой таблицей.

| Станок | Пресет | machine_type | Особенности |
|--------|--------|:------------:|-------------|
| Mirtels (все модели, ударный) | mirtels-impact | impact | step_mm=0.24 (105.8 dpi) |
| Mirtels CO2 лазер | mirtels-laser-co2 | laser_standard | step_mm=0.300 |
| САУНО График-3КЛ | sauno-graph-3kl-laser | laser_standard | стандартный |
| САУНО График-3КЛД | sauno-graph-3kld-laser80w | laser_80w | стандартный |
| САУНО График-3К | sauno-graph-3k-impact | impact | стандартный |
| Stanzone (лазер) | stanzone-laser-1bit | laser_80w | ТОЛЬКО 1-bit! |
| Stanzone (ударный) | stanzone-impact | impact | стандартный |
| STONE-ГРАФ | stonegraf-impact | impact | DPI критичен |

Для станков Mirtels ударного типа используется уменьшенный шаг `step_mm=0.24`, что соответствует разрешению 105.8 dpi и даёт более плотную точку на камне. Станок Stanzone в лазерном режиме работает **исключительно** в 1-bit режиме — попытка передать ему 8-bit файл приведёт к некорректной гравировке. Станок STONE-ГРАФ критичен к значению DPI: даже небольшое отклонение шага от рекомендованного ведёт к искажению размеров и потере качества.

## Как материал влияет на параметры

Система `MATERIAL_PROFILES` автоматически корректирует параметры обработки в зависимости от выбранного материала. Это означает, что один и тот же пресет может давать разные результаты для гранита, мрамора, габбро или акрила — и это правильное поведение, поскольку физические свойства материалов сильно различаются. Ниже описаны основные автоматические корректировки.

**step_mm** — шаг ЧПУ автоматически подстраивается под диапазон, допустимый для конкретного материала. Например, для гранита используется базовый шаг пресета, а для мрамора шаг может быть уменьшен для более деликатной обработки. Это позволяет избежать чрезмерного давления иглы или избыточной мощности лазера на мягких породах.

**stone_gamma** — гамма-коррекция камня адаптируется под отражательную способность материала. Гранит и габбро имеют тёмную поверхность с низким отражением, поэтому для них `stone_gamma` остаётся в диапазоне 0.88–1.0. Мрамор, напротив, значительно светлее, и гамма для него повышается, чтобы сохранить контрастность изображения.

**Акрил** — при выборе акрила система автоматически переключает `export_mode` в `1bit` и активирует дизеринг методом Jarvis (Jarvis dithering). Акрил не поддерживает полутона при гравировке, поэтому 8-bit режим бессмысленен: результат будет выглядеть как грязное пятно. Только 1-bit дизеринг даёт чистую, читаемую картинку на акриле.

**Мрамор** — для мрамора параметр `white_ceiling` автоматически ужесточается на -5 единиц (offset). Это связано с тем, что мрамор очень чувствителен к пережогу: даже небольшое превышение мощности на светлых участках оставляет неудаляемый жёлтый след. Уменьшение `white_ceiling` на 5 единиц гарантирует запас безопасности.

**shadow_floor** — порог тени также варьируется по материалу. Для гранита допустим `shadow_floor=5`, тогда как для мрамора и акрила порог может быть выше, чтобы избежать «грязи» в тенях из-за особенностей рассеяния света на поверхности.

## Предупреждения (alert-ы)

Система пресетов включает механизм предупреждений (alerts), который информирует оператора о потенциальных проблемах до начала обработки. Предупреждения бывают двух уровней: **WARNING** (жёлтый) — обработка возможна, но результат может быть неудовлетворительным; **ERROR** (красный) — выполнение блокируется, так как комбинация параметров гарантированно приведёт к браку.

- **Stanzone лазер = 1-bit только.** Пресет `stanzone-laser-1bit` форсирует `export_mode: 1bit`. Если вы попытаетесь переключить его в 8-bit, система выдаст предупреждение, так как Stanzone не поддерживает управление мощностью по градациям серого.

- **STONE-ГРАФ = DPI критичен.** Для станков STONE-ГРАФ точность шага критична. Если заданное разрешение не совпадает с рекомендованным, система предупредит о возможном искажении размеров изображения на камне.

- **Акрил + ударный станок = ERROR.** Эта комбинация заблокирована на уровне `validate_machine_material()`. Акрил хрупкий и не выдерживает ударную гравировку — игла пробивает материал насквозь или раскалывает его. Используйте только лазерный станок для акрила.

- **Мрамор + ударный станок = WARNING.** Ударная гравировка по мрамору технически возможна, но результат обычно неудовлетворительный: мрамор крошится под иглой, линии получаются неровными, а глубина непредсказуемой. Рекомендуется использовать лазерный станок.

- **Laser 80W + гранит = WARNING.** Мощный лазер на граните может вызвать пережог (белый ореол вокруг светлых участков) из-за завышенного `white_ceiling`. Система автоматически снижает `white_ceiling` для гранита при работе с 80W лазером, но оператору следует визуально контролировать результат на тестовом образце.

## Несовместимые комбинации

Функция `validate_machine_material()` проверяет сочетание типа станка и материала перед запуском обработки. Это最后一 линия защиты от дорогостоящего брака. Все несовместимые комбинации определены на основе практического опыта и тестирования на реальных станках.

**acrylic + impact = ERROR** — выполнение полностью блокируется. Ударная игла разрушает акрил, и никакая настройка параметров не сделает эту комбинацию рабочей. Если вам нужно выгравировать изображение на акриле, выберите лазерный станок и пресет с `export_mode: 1bit` + Jarvis dithering.

**marble + impact = WARNING** — обработка не блокируется, но оператор получает предупреждение. Ударная гравировка по мрамору даёт нестабильный результат: точка «плывёт», крошка забивает соседние пиксели, а контраст обычно ниже ожидаемого. Если вы всё же решите продолжить, рекомендуется уменьшить `shadow_floor` и увеличить `shadow_noise_min` для сглаживания артефактов.

**laser_80w + granite = WARNING** — мощный лазер на граните создаёт риск пережога (white_ceiling burn). Проблема проявляется в виде светлых «ореолов» вокруг ярких деталей изображения. Система автоматически уменьшает `white_ceiling` на несколько единиц, но для некоторых сортов гранита этого может быть недостаточно. Рекомендуется сделать тестовый прогон на обрезке камня перед запуском основного заказа.

## CLI примеры

Для работы с пресетами из командной строки используется модуль `retouch`. Ниже приведены типичные сценарии запуска обработки с различными пресетами и параметрами. Каждый пример включает пояснение, что именно он делает.

Запуск обработки с пресетом Stanzone (лазерный, 1-bit):
```bash
python -m retouch process -i photo.jpg -o out.bmp --preset stanzone-laser-1bit
```
Этот пример использует пресет `stanzone-laser-1bit`, который автоматически выставляет `export_mode: 1bit` и метод дизеринга Jarvis. Идеально подходит для станков Stanzone с лазерной головкой.

Запуск обработки с пресетом Mirtels и указанием материала:
```bash
python -m retouch process -i photo.jpg -o out.bmp --preset mirtels-impact --material gabbro
```
Здесь пресет `mirtels-impact` задаёт тип станка `impact` и `step_mm=0.24`, а параметр `--material gabbro` активирует профиль материала габбро, который корректирует `stone_gamma` и `shadow_floor` под эту породу.

Запуск обработки с явным указанием типа станка и материала (без пресета):
```bash
python -m retouch process -i photo.jpg -o out.bmp -m impact --material marble
```
В этом режиме система использует значения по умолчанию для `impact` станка, но применяет профиль мрамора, который автоматически ужесточит `white_ceiling` на -5 единиц и повысит `stone_gamma`. Обратите внимание: без пресета вы берёте на себя ответственность за корректность параметров.

Просмотр списка всех доступных пресетов:
```bash
python -m retouch --list-presets
```
Команда выводит таблицу со всеми пресетами, их `machine_type` и кратким описанием. Полезно для быстрого поиска нужного пресета перед запуском обработки.
