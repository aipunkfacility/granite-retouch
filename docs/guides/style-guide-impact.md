# Стиль генерации: ударная гравировка

Целевой стиль: **Granite Micro-Contrast Portrait** — для ударной гравировки по камню (алмазная игла).

Ударный станок работает принципиально иначе чем лазер: алмазная игла бьёт по камню, создавая точки. Чем светлее пиксель — тем больше точек и глубже удар. Полностью чёрные пиксели игла пропускает. Поэтому для impact критично: **микроконтраст вместо гладкости**, и **умеренная яркость вместо пересвета**.

## Ключевые требования

### Материальность и текстура

- **Кожа:** Видимая текстура пор и микрорельеф. Игла должна «видеть» каждую точку — гладкие области без текстуры превращаются в неразличимое пятно на камне. Лёгкая пористость обязательна, но без шума и зерна.
- **Волосы:** Чёткие, раздельные пряди с выраженным контрастом. Игла хорошо считывает резкие переходы — каждый локон должен быть отделён от соседнего тёмной тенью.
- **Одежда:** Резкая, почти гравюрная детализация ткани. Складки — с жёсткими тенями, не мягкими градиентами. Impact-станок хорошо передаёт текстуру, если она контрастная.

### Технические параметры

- Лицо: яркость 185–210 (умеренная — пересвет критичнее чем для лазера, игла не различает оттенки выше 240)
- Inner Glow: 10–25px, opacity 60–80% (узкий, яркий контур — чёткая граница для иглы)
- Shadow noise: включён — игла не бьёт в полностью чёрные пиксели, шум даёт «зацепку»
- Общий стиль: «микроконтрастная чёткость», видимые поры, резкие переходы

## Критичные ограничения (специфика impact)

- **Пересвет — главный враг:** Яркость лица выше 240 = игла не различает детали, всё сливается в белое пятно. Face brightness target строго 185–210.
- **Чёрные провалы:** Полностью чёрные области (< 10) игла пропускает — появляются «дыры» в портрете. Shadow noise добавляет минимальную яркость в тени.
- **Мягкие градиенты — плохо:** Игла плохо передаёт плавные переходы, нужна чёткая «ступенчатость» тонов.

## Negative Constraints (запрещено)

- **Никакого пересвета:** Лицо не должно быть светлее 210 — это критично для ударной гравировки
- **Никакой гладкой «фарфоровой» кожи:** Гладкость = потеря деталей при ударной гравировке
- **Никакого цифрового шума (Grain):** Шум ≠ текстура пор. Зерно выглядит как брак на камне
- **Никаких мягких градиентов на одежде:** Складки должны быть контрастными, не «мыльными»

## Как использовать в промпте

Добавьте в промпт для агента-промптера:

> Follow the aesthetic standards described in `style-guide-impact.md`: prioritize micro-contrast, visible skin pores, sharp fabric folds, and moderate face brightness (185–210). Avoid airbrushed smoothness — the diamond needle needs texture edges to read.
