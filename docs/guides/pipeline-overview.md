# Как работает пайплайн обработки

Что происходит с фотографией от загрузки до готового файла для станка.
Без кода, без схем — просто по шагам, что и зачем делает программа.

## Весь процесс за 10 секунд

Берём фотографию с синим фоном (AI-ретушь), вырезаем человека,
превращаем в чёрно-белое, делаем лицо светлым и контрастным,
добавляем свечение по контуру, убираем всё лишнее с фона,
сохраняем для станка.

## По шагам

### 1. Удаление синего фона

Фотография приходит с синим хромакеем — это фон, который нейросеть
нарисовала за человеком. Программа «вырезает» человека: чем синее
пиксель, тем прозрачнее он становится. По краям — плавный переход,
чтобы не было жёсткой обрезки («зубцов»). Ещё убирает синюю каёмку
вокруг волос (fringe), если хромакей немного «залез» на человека.

**На выходе:** человек на прозрачном фоне + маска силуэта (чёрный фон,
белый человек) — она понадобится дальше, чтобы обрабатывать только
человека, не трогая фон.

### 2. Превращение в чёрно-белое

Цвет больше не нужен — гравировка всё равно чёрно-белая. Программа
переводит картинку в оттенки серого (256 градаций: 0 = чёрный,
255 = белый).

### 3. Замер: анализ фотографии

Программа измеряет 13 характеристик изображения — но оператору
достаточно знать, что она определяет:

-   **Общая яркость лица** — тёмное фото, нормальное или пересвеченное
-   **Диапазон яркостей** — есть ли на лице и глубокие тени, и светлые
    участки
-   **Завал в черноту или пересвет** — не ушли ли детали в 0 или 255
    (там они потеряются)

Эти замеры нужны, чтобы следующие шаги сами подстроились под
конкретное фото — не гадать вслепую.

### 4. Определение зоны лица

Где у человека лицо? Программа может найти его тремя способами:

-   **Автоматически** — по форме силуэта (где голова переходит в плечи,
    там уровень скул). Работает для ~85% портретов, но на AI-ретушах
    часто ошибается, потому что нейросеть рисует плавный силуэт
    без чёткого перехода голова-шея.
-   **Вручную** — оператор в Web UI рисует овал лица. Всегда
    исправляет автоопределение, если оно встало не туда.
-   **Через нейросеть (mediapipe)** — пока не используется, но можно
    добавить, когда понадобится точная маска лица.

**Важно:** автоопределение — это заготовка, а не истина. Оператор
всегда смотрит и при необходимости двигает овал. Когда овал
передвинут вручную, он «запинается» и больше не сбивается
при новом предпросмотре (Pin Face Oval).

Из овала программа делает две маски:

-   **Маска лица** — то, что внутри овала, ограниченное силуэтом
-   **Маска волос** — то, что выше лица, но внутри силуэта

### 5. Свечение по контуру (Glow)

Самый заметный визуальный эффект. Вдоль контура человека (по краю
силуэта) добавляется мягкое свечение. Оно не даёт фигуре «сливаться»
с чёрным фоном на гравировке.

Два режима:

-   **Inner Glow** — свечение внутрь человека (рекомендуемый).
    Ярче на тёмных участках контура (волосы, тёмная одежда), слабее
    на светлых (лицо). Смотрится естественно.
-   **Outer Glow** — свечение наружу (классический ореол вокруг
    фигуры).

Настройки зависят от станка:

-   **Лазер 20–40W:** широкое, мягкое свечение (40–80 пикселей)
-   **Лазер 60–80W:** фиксированное, меньше (20 пикселей) — мощный
    лазер сам даёт контраст
-   **Ударный станок (Impact):** зависит от фото — если фон и человек
    плохо разделяются, свечение усиливается

### 6. Общая яркость (Levels)

Программа смотрит на медианную яркость лица и доводит её до целевого
значения для данного станка. Например для лазера 20–40W цель —
210 из 255, для Impact — 180.

Если фото тёмное — поднимает яркость, светлое — опускает. Но не до
бесконечности: есть ограничитель, чтобы не выжечь света в белое
пятно (защита от клиппинга).

**Что не трогает:** фон остаётся чёрным — коррекция применяется только
внутри силуэта человека.

### 7. Яркость лица (Face Brightness)

Отдельная тонкая настройка по маске лица — только кожа, без волос
и одежды. Если лицо после общего подъёма яркости всё ещё тёмное
или, наоборот, пересвечено — программа корректирует его ещё раз,
но **нелинейно**:

-   Тени поднимает полностью
-   Света почти не трогает

Это значит: тёмное лицо станет светлее, но белый воротник не
пересветится.

**Цели для разных станков:**

-   Лазер 20–40W: яркость лица 230–245 (почти белое)
-   Лазер 60–80W: 190–210
-   Impact: 200–225

### 8. Резкость (Unsharp Mask)

Чёткость добавляется по всему силуэту человека, кроме фона.
Если аналитика показала, что фото и так пересвечено — резкость
снижают (пересвету резкость не нужна). Если диапазон яркостей
узкий (плоский портрет) — наоборот, усиливают.

### 9. Шум в тенях (только Impact)

Ударные станки (игла) не бьют в чисто чёрные пиксели — игла
«залипает» на нуле. Поэтому для Impact в тёмных областях
(яркость < 30) добавляется мелкий случайный шум. По сути —
«зацепки» для иглы, невидимые глазу, но критичные для работы
станка.

### 10. Виньетка

Программа рисует эллипс, размывает его края и накладывает на
изображение сверху — получается плавный переход по краям кадра
(как затемнение на старых фотографиях). Параметр `headroom`
отвечает за то, чтобы макушка головы не обрезалась виньеткой
(частая проблема — нужно увеличить, если обрезает).

Детально про параметры виньетки — в отдельном руководстве
[`vignette.md`](vignette.md).

### 11. Сохранение

Готовое изображение сохраняется в формате, который понимает станок:

-   **8-bit BMP** — 256 оттенков серого, основной формат для всех
    станков
-   **1-bit BMP** — чёрно-белый (0 — нет, 1 — есть). Если нужно,
    оператор может включить дизеринг (Jarvis или Stucki), чтобы
    имитировать полутона точками. Предпросмотр дизеринга —
    отдельная кнопка в Web UI, потому что считается долго.

## Что оператор видит в Web UI

В интерфейсе можно:

1.  Переключаться между шагами пайплайна и видеть, как меняется
    изображение (Step Selector)
2.  Править овал лица (Face Oval Overlay)
3.  Смотреть диагностику: яркость лица до/после, фактор коррекции,
    ошибки качества
4.  Выбирать станок (laser_standard / laser_80w / impact)
5.  Менять стиль свечения (inner / outer)
6.  Смотреть предпросмотр дизеринга (если нужно 1-bit)

## Что может пойти не так

-   **Фото пересвечено** — слишком высокий целевой диапазон яркости
    лица. Опустить в настройках.
-   **Воротник пересвечен** — маска лица не ограничивает коррекцию.
    Проверить овал лица.
-   **Белый фон вместо чёрного** — хромакей не распознан. Понизить
    порог синего в конфиге.
-   **Голова обрезана виньеткой** — увеличить headroom.
-   **Серая дымка на фоне** — коррекции залезли на фон. Должно
    фиксироваться маской силуэта, если баг — сообщить разработчикам.
