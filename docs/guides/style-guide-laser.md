# Стиль генерации: лазерная гравировка

Целевой стиль: **Granite High-End Airbrush** — для лазерной гравировки по чёрному граниту (габбро).

ИИ не должен имитировать «фотографию» (поры, шум, дефекты). ИИ должен выступать в роли академического художника, создающего идеализированный, скульптурный рендер.

## Ключевые требования

### Материальность и текстура

- **Кожа:** Сбалансированная, естественная текстура. Избегать гипер-детализации пор, но сохранять лёгкую естественную пористость для предотвращения «воскового» эффекта. Только мягкие, математически выверенные градиенты света и тени.
- **Волосы:** Крупные, скульптурные пряди. Исключить «пушистость» и отдельные волоски. Волосы — единая масса с жёстким контрастом (ярко-белые блики / глубоко-чёрные тени).
- **Одежда:** Тонкая, реалистичная фактура ткани для глубины, без грубого цифрового шума (Grain). Складки и объём — мягкими серыми градиентами.

### Технические параметры

- Лицо: яркость 230–245 (очень светлое — лазер «выжигает» светлые участки)
- Inner Glow: 40–80px, opacity 30–40% (широкий, мягкий контур)
- Общий стиль: «фарфоровая кожа», скульптурный объём

## Negative Constraints (запрещено)

- **Никакого гипер-фотореализма:** Избегать чрезмерной детализации пор, глубоких морщин или дефектов кожи
- **Никакой живописи:** Никаких мазков кисти, «рисованности», эффекта комикса
- **Никакого цифрового шума:** Grain недопустим
- **Никаких 3D-рендер артефактов:** Лицо не должно выглядеть как восковая кукла или персонаж игры. Это идеальная студийная ретушь

## Как использовать в промпте

Добавьте в промпт для агента-промптера:

> Follow the aesthetic standards described in `style-guide-laser.md`: prioritize airbrushed smoothness, sculpted 3D volume, and clean, vector-sharp facial features while maintaining a professional memorial portrait look.
