# Стиль генерации: мощный лазер 60–80W+

Целевой стиль: **Restored Photograph, Natural Dignified Warm** — для мощной лазерной гравировки по камню (габбро/гранит) на станках с лазерами 60W и выше.

Мощный лазер работает иначе чем стандартный 20–40W: при 60–80W выжигание глубже, и то, что на стандартном лазере выглядит как лёгкий блик, на мощном пережигается в белое пятно. Поэтому для laser_80W нужен **medium-key** вместо high-key: лицо умеренной яркости, морщины сохранены, блики приглушены.

> **Для стандартных лазеров 20–40W** см. [style-guide-laser.md](style-guide-laser.md) — там целевой стиль Granite High-End Airbrush с яркостью лица 230–245.

## Ключевые требования

### Материальность и текстура

- **Кожа:** Сохранённые морщины как мягкие тональные переходы. В отличие от laser_standard (абсолютная гладь — «фарфоровая кожа»), для laser_80W морщины остаются, но убираются поры/шум — «clean but not sterile». Лёгкая естественная текстура, но без гипер-реализма.
- **Волосы:** Тёмная масса с мягкими бликами (DARKER 2–3 stops по сравнению с laser_standard). При мощном лазере яркие блики пережигаются, поэтому контраст снижается: тёмная масса + скульптурный объём вместо ярко-белых прядей. Скульптурный объём обязателен — волос должен выглядеть как 3D-масса.
- **Одежда:** Тонкая, реалистичная фактура ткани. Blowout без деталей запрещён — светлый воротник ОК, но полностью выбеленная грудь/плечи — брак.

### Технические параметры

- Лицо: медиана 160–180, блики 180–200, тени 120–150
- Outer Glow: минимальный (15–25px, 10–20%) — мощный лазер сам создаёт контраст, ореол наружу
- White ceiling: 235 (кроме eye whites), highlight_start: 195 — при 60–80W значения выше 235 пережигаются
- Общий стиль: «восстановленная фотография», натуральный, тёплый, достойный

### Апертура и свет

- **Апертура: f/11** — средняя глубина резкости, достаточная для портрета
- Rim light: **запрещён** — pipeline делает Outer Glow, дополнительный rim light в генерации создаёт двойной контур

## Negative Constraints (запрещено)

- **Никакого high-key:** Яркость лица 230+ при мощном лазере = пережжённое белое пятно на камне
- **Никакого blowout одежды:** Белая грудь/плечи без деталей — брак
- **Никакого rim light:** Pipeline уже добавляет Outer Glow, двойной контур недопустим
- **Никакого цифрового шума:** Grain недопустим (как и для laser_standard)
- **Никаких ярких бликов волос:** Белые пряди при 60–80W превращаются в пережжённые линии
- **Никакого гипер-фотореализма пор:** Поры/шум убираются, морщины — остаются

## Как использовать в промпте

Добавьте в промпт для агента-промптера:

> Follow the aesthetic standards described in `style-guide-laser-80w.md`: prioritize natural, dignified warmth with preserved wrinkle transitions, darker hair mass with soft sculptural highlights (2–3 stops darker than laser_standard), and medium-key face brightness (190–210 median). Avoid high-key overbright, rim light, and clothing blowout. Ceiling: 235 except eye whites.
