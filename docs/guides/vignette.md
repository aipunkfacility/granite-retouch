# Арховая виньетка

Портрет для гравировки на памятнике — не прямоугольник. Нижняя часть обрезается аркой (полукругом), чтобы портрет вписывался в форму памятника. Верх (голова) всегда остаётся целиком видимым.

Виньетка — это маска видимости: пиксели внутри арки видны, снаружи — чёрный фон (#000000). Край арки плавно размыт, чтобы переход не был резким (резкие границы дают брак при гравировке).

## Как это работает

Виньетка — это эллипс, нарисованный на чёрной маске и размытый Gaussian Blur. Эллипс вынесен **выше верхней границы изображения**, чтобы голова гарантированно попадала внутрь арки.

```
                         arch_top_y (выше изображения, невидимо)
                            ↓
        ┌───────────────────┼────────────────────┐
        │              ╱    │    ╲                │ ← верхняя дуга эллипса
        │           ╱      │      ╲             │    (выше img = голова видна)
        │         ╱        │        ╲           │
        │       ┌─────────────────────────┐     │
        │       │                         │     │
        │       │      ПОРТРЕТ            │     │
        │       │      (видим)            │     │
        │       │                         │     │
        │       └───────┘         └───────┘     │ ← нижняя дуга эллипса
        │      ██                             ██│    (углы = чёрный фон)
        │     ████         arch_bottom_y    ████│
        └───────────────────────────────────────┘
```

## Параметры (config.yaml → vignette)

Все параметры — доля от размера изображения, поэтому виньетка масштабируется автоматически на любом разрешении.

| Параметр | Значение | Единица | Что делает |
|----------|----------|---------|-----------|
| `vertical_offset` | 0.10 | доля высоты | Отступ нижнего края арки от низа изображения |
| `vertical_diameter` | 0.50 | доля высоты | Высота эллипса (определяет ширину арки) |
| `blur_radius` | 60 | пиксели | Размытие края виньетки |
| `headroom` | 0.6 | доля высоты | Запас над головой (эллипс вынесен выше изображения) |
| `horizontal_oversize` | 0.2 | доля ширины | Расширение эллипса за пределы изображения по бокам |

### Формулы

Для изображения `W × H`:

```
arch_bottom_y = H - (H × vertical_offset)
arch_top_y    = arch_bottom_y - (H × vertical_diameter) - (H × headroom)
ellipse_left  = -(W × horizontal_oversize)
ellipse_right = W + (W × horizontal_oversize)
```

Полное описание всех параметров см. в [reference/config.md](../reference/config.md).

## Как регулировать

### Голова обрезается

Симптом: верхняя часть головы (лоб, макушка) затемнена.

Решение: увеличить `headroom`.

```yaml
vignette:
  headroom: 0.8    # было 0.6, увеличили запас
```

### Слишком много чёрного по бокам

Симптом: плечи/воротник уходят в чёрный фон.

Решение: увеличить `vertical_diameter` или `horizontal_oversize`.

```yaml
vignette:
  vertical_diameter: 0.60    # было 0.50, арка стала шире
  horizontal_oversize: 0.3   # было 0.2, эллипс шире по бокам
```

### Слишком много чёрного внизу

Симптом: нижняя часть портрета (рубашка, пиджак) обрезана высоко.

Решение: уменьшить `vertical_offset`.

```yaml
vignette:
  vertical_offset: 0.05    # было 0.10, арка опущена ниже
```

### Край арки слишком резкий

Симптом: видна чёткая граница между портретом и чёрным фоном.

Решение: увеличить `blur_radius`.

```yaml
vignette:
  blur_radius: 80    # было 60, переход мягче
```

### Край арки слишком мыльный

Симптом: плавный переход занимает слишком много места, теряются детали у края.

Решение: уменьшить `blur_radius`.

```yaml
vignette:
  blur_radius: 40    # было 60, переход чётче
```

## Пресеты

### Стандартный портрет (по умолчанию)

Универсальный пресет для большинства заказов.

```yaml
vignette:
  vertical_offset: 0.10
  vertical_diameter: 0.50
  blur_radius: 60
  headroom: 0.6
  horizontal_oversize: 0.2
```

### Широкая арка (погоны, ордена)

Нужно сохранить детали на плечах и груди — военные, с наградами.

```yaml
vignette:
  vertical_offset: 0.08
  vertical_diameter: 0.65
  blur_radius: 60
  headroom: 0.6
  horizontal_oversize: 0.3
```

### Узкая арка (овальный медальон)

Портрет в овале — минимум деталей вокруг лица.

```yaml
vignette:
  vertical_offset: 0.15
  vertical_diameter: 0.40
  blur_radius: 50
  headroom: 0.7
  horizontal_oversize: 0.1
```

### Мягкий переход (ударный станок)

Ударная гравировка чувствительна к резким границам — увеличиваем blur.

```yaml
vignette:
  vertical_offset: 0.10
  vertical_diameter: 0.50
  blur_radius: 80
  headroom: 0.6
  horizontal_oversize: 0.2
```

## Запуск обработки

```bash
# Стандартная обработка (параметры из config.yaml)
python -m retouch process -i ai.png -o final.tiff -m laser

# Нестандартная арка (временный конфиг)
python -m retouch process -i ai.png -o final.tiff -m laser -c /tmp/config_oval.yaml

# Ударный станок — мягкий переход автоматически (если blur_radius: 80 в config.yaml)
python -m retouch process -i ai.png -o final.tiff -m impact
```

### Когда менять пресет

| Признак заказа | Действие |
|---------------|---------|
| Военный в форме с погонами | Пресет «Широкая арка» |
| Овальный медальон | Пресет «Узкая арка» |
| Ударный станок | Пресет «Мягкий переход» (или просто `blur_radius: 80`) |
| Обычный гражданский портрет | Стандартный пресет (ничего менять) |

### Валидация результата

После обработки проверить:
- Голова видна целиком (макушка, лоб, волосы не обрезаны)
- Плечи не уходят в чёрный (если это не овальный медальон)
- Переход плавный, без чёткой границы
- Чёрный фон абсолютно чёрный (#000000)
